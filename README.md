# موقع سيفتى هوم

موقع كتالوج بالعربي والإنجليزي: الزبون يتفرّج على الأبواب ويطلب على واتساب.

## التعديل من الداشبورد
افتح https://app.pagescms.org وادخل بحساب GitHub، واختار الريبو.

- **المنتجات:** تضيف باب جديد، أو تغيّر الصور والأسعار والمقاسات. أي سعر تسيبه فاضي بيظهر مكانه «اسأل عن السعر».
- **بيانات الموقع:** رقم الواتساب، والعنوان، والمواعيد، ولينك الخريطة، وفيديو الرئيسية، وكود Meta Pixel.

بعد ما تحفظ، الموقع بيتحدّث لوحده في خلال دقيقتين تقريبًا.

## ملاحظات
- **الصور:** يفضّل webp أو jpg على خلفية بيضا، والباب واخد الصورة كلها.
- **ألوان WPC:** كل لون ليه صورة صغيرة في `public/swatches/<كود اللون>.webp`، واسمه في `src/data/colors.ts`.
- **الأقسام ومواصفاتها:** موجودة في `src/data/categories.ts`.

## تشغيل محلي
```
npm install
npm run dev
```
